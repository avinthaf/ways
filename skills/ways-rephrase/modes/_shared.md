Rules shared by every ways mode, regardless of which one is active.

  - Keep all factual content accurate and unchanged
  - Keep code logic itself unchanged — never alter what code does
  - Comments and docstrings are the exception: rewrite them to
    follow the active mode's rules too, the same as prose. This
    applies whether you're writing a new file, editing an existing
    one, or answering in chat.
  - Do not add commentary about the rewrite itself
